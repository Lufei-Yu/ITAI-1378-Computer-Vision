# Lab 03 — Using Classic ML in Computer Vision

## 1. Problem Statement

Computer vision systems often need to process images with different lighting conditions, low contrast, noise, or unclear visual details. These challenges can make it difficult to identify important features and accurately interpret image content.

The purpose of this lab is to explore image enhancement and processing techniques that improve visual quality and make image information easier to analyze. These techniques are especially useful in medical imaging, where enhancing X-ray or MRI images can help make important structures more visible. The lab also introduces methods for comparing image-processing results and understanding how different transformations affect visual information.

## 2. Approach

The lab explores image-processing techniques through practical coding exercises. The workflow involves loading images, applying enhancement operations, visualizing the outputs, and comparing the results with the original images.

Key methods may include:

- **Image loading and visualization:** Load sample images and examine their original appearance.
- **Contrast enhancement:** Improve the visibility of details in images with limited contrast.
- **Histogram analysis:** Examine pixel intensity distributions to understand image brightness and contrast.
- **Image transformations:** Apply mathematical transformations to adjust image intensity and improve the visibility of details.
- **Image comparison:** Compare original and processed images to evaluate the visual effects of different techniques.

The objective is to understand how image-processing operations influence image quality and determine which methods are appropriate for different visual-analysis tasks.


## 3. Results

The expected outcome is a better understanding of how image enhancement techniques affect image appearance and the visibility of important details.

## 4. Key Findings

This lab demonstrates that image enhancement can improve the visibility of important visual information without necessarily changing the underlying content of an image. Different processing methods can produce different results, so selecting an appropriate technique depends on the image characteristics and the intended application.

I also learned the importance of comparing processed images with their original versions. Visual inspection helps reveal whether a transformation improves contrast and detail or introduces unwanted changes. These concepts are useful for developing more advanced computer vision systems that rely on clear and informative image inputs.
