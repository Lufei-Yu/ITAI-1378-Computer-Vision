# Lab 02 — Image Processing Fundamentals

## 1. Problem Statement

Computer vision enables computers to interpret and analyze visual information from images. However, working with image data requires an understanding of how images are represented digitally, how pixels store visual information, and how image-processing techniques can modify or extract useful information from images.

The purpose of this lab is to explore fundamental computer vision concepts and practice applying image-processing techniques using programming tools. These skills provide a foundation for more advanced applications, including object detection, image classification, image segmentation, and AI-powered visual recognition systems.

## 2. Approach

This lab focuses on understanding image data and applying computer vision techniques through hands-on exercises.

The general approach includes:

- **Image loading and visualization:** Load image data and display images to inspect their visual properties.
- **Image representation:** Explore how images are represented as pixel values in numerical arrays.
- **Image processing:** Apply basic image transformations and processing operations to observe how they affect visual information.
- **Result comparison:** Compare original images with processed images to understand the effects of different operations.
- **Code experimentation:** Modify parameters and test different inputs to develop a better understanding of image-processing workflows.



## 3. Results

The lab provides practical experience with image data and basic computer vision workflows. Results can be evaluated by checking whether the code executes successfully, whether the processed images match the expected transformations, and whether the visual differences can be explained.


## 4. Key Findings

Through this lab, I developed a better understanding of how computers represent and process visual information. I learned that image-processing results depend on the input data, pixel representation, and the operations applied to an image.

The exercises also helped me connect theoretical computer vision concepts with practical programming. Visualizing intermediate results is useful for identifying errors and understanding how each processing step changes the image.

These foundational skills will be useful for future projects involving object detection, image classification, and other AI applications that require computers to analyze images.
