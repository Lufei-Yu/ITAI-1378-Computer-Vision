# Computer Vision – Laboratory Exercises

## 1. Overview

This folder contains hands-on laboratory exercises completed as part of the ITAI 1378 – Computer Vision course.

The labs explore fundamental and advanced computer vision concepts, including image classification, Convolutional Neural Networks (CNNs), transfer learning, object detection, and Visual Language Models (VLMs).

Each lab provides practical experience with Python-based AI techniques and demonstrates how computer vision systems process, analyze, recognize, and interpret visual information.

## 2. Learning Objectives

Through these laboratory exercises, the main learning objectives are:

- Understand the fundamentals of computer vision and image processing.
- Explore image classification and visual feature extraction.
- Implement deep learning models using Convolutional Neural Networks.
- Apply transfer learning using pre-trained models.
- Understand object detection and object localization.
- Explore multimodal AI and Visual Language Models.
- Evaluate AI model performance and interpret experimental results.
- Develop practical skills using Python and Jupyter Notebooks.

## 3. Lab Exercises

| Lab | Topic | Description |
|---|---|---|
| [Lab 04](./Lab%2004/) | Chihuahua or Muffin Workshop | Explore image recognition and classification through visually similar images. |
| [Lab 05](./Lab%2005/) | Chihuahua or Muffin with CNN | Apply Convolutional Neural Networks to image classification. |
| [Lab 06](./Lab%2006/) | Object Detection Using Transfer Learning | Explore pre-trained models and transfer learning for object detection. |
| [Lab 08](./Lab%2008/) | Visual Language Models (VLMs) | Explore multimodal AI by combining image understanding and natural language processing. |

## 4. Technologies Used

The laboratory exercises use various tools, libraries, and AI technologies, including:

- **Python** – Primary programming language.
- **Jupyter Notebook** – Interactive development and experimentation environment.
- **Google Colab** – Cloud-based notebook execution.
- **NumPy** – Numerical computation and data processing.
- **Matplotlib** – Image visualization and result analysis.
- **TensorFlow / Keras / PyTorch** – Deep learning frameworks, depending on the lab.
- **Convolutional Neural Networks (CNNs)** – Deep learning for image classification.
- **Transfer Learning** – Reusing pre-trained models for computer vision tasks.
- **Object Detection** – Identifying and locating objects in images.
- **Visual Language Models (VLMs)** – Connecting visual information with natural language.
